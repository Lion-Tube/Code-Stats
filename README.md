## ما الذي تفعله هذه الأداة؟

تعطيك نظرة شاملة وسريعة على أي مشروع برمجي بأمر واحد فقط:

- **نظرة عامة على المشروع** — عدد الملفات، المجلدات، إجمالي الأسطر، أسطر الكود، التعليقات، الأسطر الفارغة، ونسبة الكود.
- **تحليل اللغات** — جدول مفصّل لكل لغة برمجية في مشروعك مع شريط بصري ونسبة مئوية وتصنيف تلقائي يوضح مدى هيمنة كل لغة على المشروع.
- **مخطط شجري** — عرض ملوّن وهيكلي كامل لمجلدات وملفات المشروع.

## المتطلبات

- **Rust** الإصدار 1.70 أو أحدث.

إذا لم يكن Rust مثبتاً على جهازك، قم بتثبيته من [rustup.rs](https://rustup.rs) عبر الأمر:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

بعد التثبيت أعد تشغيل الطرفية ثم تحقق:

```bash
rustc --version
cargo --version
```

## التثبيت

### الخطوة الأولى — استنساخ المستودع

```bash
git clone https://github.com/lion-cube/code-stats
cd code-stats
```

### الخطوة الثانية — بناء وتثبيت الأداة

```bash
cargo install --path .
```

هذا الأمر يقوم بتجميع الأداة ووضع الملف التنفيذي في مجلد `~/.cargo/bin/`.

### الخطوة الثالثة — التحقق من إضافة المسار

تأكد أن الأمر يعمل:

```bash
code-stats --version
```

إذا ظهرت رسالة `command not found`، أضف هذا السطر لملف إعدادات الـ shell الخاص بك (`~/.bashrc` أو `~/.zshrc`):

```bash
export PATH="$HOME/.cargo/bin:$PATH"
```

ثم أعد تحميل الإعدادات:

```bash
source ~/.bashrc
```

## طريقة الاستخدام

### تحليل المجلد الحالي (عرض كل شيء)

```bash
code-stats .
```

### تحليل مشروع في مسار محدد

```bash
code-stats /path/to/your/project
```

### الأوامر الفرعية

| الأمر | الوصف |
|-------|-------|
| `code-stats . all` | عرض كل شيء — نظرة عامة + جدول اللغات + المخطط الشجري (الافتراضي) |
| `code-stats . stats` | عرض النظرة العامة فقط |
| `code-stats . lines` | عرض جدول تحليل اللغات فقط |
| `code-stats . tree` | عرض المخطط الشجري فقط |

### الخيارات الإضافية

| الخيار | الوصف | مثال |
|--------|-------|------|
| `--ignore-ext` | تجاهل ملفات بامتدادات معينة | `--ignore-ext txt,log,lock` |
| `--ignore-dir` | تجاهل مجلدات معينة | `--ignore-dir tests,docs,dist` |

### مثال مركّب

```bash
code-stats /my/project lines --ignore-ext lock --ignore-dir dist,tests
```

### شرح تصنيف هيمنة اللغة

| التصنيف | المعنى |
|---------|--------|
| `Dominant` | اللغة الرئيسية في المشروع، تمثل 60% أو أكثر من الكود |
| `Major` | لغة مهمة جداً، تمثل من 30% إلى 59% |
| `Significant` | حضور ملحوظ، من 10% إلى 29% |
| `Minor` | حضور بسيط، من 1% إلى 9% |
| `Negligible` | حضور شبه معدوم، أقل من 1% |
