## 💡 فكرة المشروع

**code-stats** هي أداة سطر أوامر خفيفة وسريعة مكتوبة بلغة **Rust**، هدفها إعطاؤك نظرة شاملة وسريعة على أي مشروع برمجي. بدلاً من أن تفتح المتصفح وتعد الملفات يدوياً، تشغّل أمراً واحداً وتحصل على كل شيء.

الأداة تقوم بثلاثة أشياء أساسية:

**أولاً — إحصاء الأسطر:** تقرأ كل ملف في مشروعك وتحسب عدد أسطر الكود الفعلية، وأسطر التعليقات، والأسطر الفارغة، مع عرض إجمالي لكل نوع ملف حسب الامتداد.

**ثانياً — إحصاء الملفات والمجلدات:** تعطيك نظرة عامة تشمل عدد الملفات الكلي، عدد المجلدات، نسبة الكود إلى الإجمالي، وغيرها من الأرقام المفيدة.

**ثالثاً — مخطط شجري ملوّن:** تعرض هيكل مشروعك بشكل مرئي جميل مع أيقونات لكل نوع ملف وألوان مختلفة حسب لغة البرمجة.

## 🚀 التثبيت

### من المصدر (يحتاج Rust مثبّت)

```bash
# استنسخ المستودع
git clone https://github.com/lion-tube/code-stats
cd code-stats

# ابنِ وثبّت الأداة
cargo install --path .
```

### التشغيل المباشر بدون تثبيت

```bash
cargo run -- [المسار] [الأمر]
```

---

## 📖 طريقة الاستخدام

### عرض كل شيء دفعة واحدة (الافتراضي)

```bash
code-stats /path/to/your/project
# أو من داخل المشروع:
code-stats .
```

### أوامر محددة

| الأمر | الوصف |
|-------|-------|
| `code-stats . all` | عرض كل المعلومات (افتراضي) |
| `code-stats . stats` | إحصائيات سريعة فقط |
| `code-stats . lines` | تفصيل الأسطر حسب نوع الملف |
| `code-stats . tree` | مخطط شجري للمشروع |

### خيارات متقدمة

```bash
# تجاهل امتدادات معينة
code-stats . --ignore-ext txt,log,md

# تجاهل مجلدات إضافية
code-stats . --ignore-dir tests,docs

# تجميع الخيارات
code-stats /my/project lines --ignore-ext lock --ignore-dir dist
```

## 🛠️ التقنيات المستخدمة

الأداة مبنية على مكتبات Rust الآتية:

- **[clap](https://crates.io/crates/clap)** — لبناء واجهة سطر الأوامر بشكل احترافي مع دعم الأوامر الفرعية والحجج.
- **[colored](https://crates.io/crates/colored)** — لإضافة الألوان والتنسيق الجميل على الطرفية.
- **[walkdir](https://crates.io/crates/walkdir)** — للتنقل بكفاءة عبر مجلدات المشروع بشكل متعدد المستويات.

---

## 🧠 كيف يعمل الكود؟

الأداة تعمل على ثلاث مراحل متسلسلة:

**مرحلة المسح:** تستخدم `walkdir` للتنقل عبر كل ملفات المشروع بشكل متكرر، مع تجاهل الدلائل غير الضرورية مثل `.git` و`target` و`node_modules` تلقائياً.

**مرحلة التحليل:** لكل ملف تقرأ محتواه سطراً بسطر، وتصنّف كل سطر إلى: سطر كود، سطر تعليق (يعتمد على امتداد الملف لمعرفة رمز التعليق الصحيح)، أو سطر فارغ.

**مرحلة العرض:** تجمّع النتائج حسب امتداد الملف، وترسم أشرطة بيانية نسبية، وتعرض المخطط الشجري بالألوان والأيقونات.
